# 📊 JobPulseAI – AI-Powered Career Intelligence Platform

> Plateforme intelligente d'analyse du marché de l'emploi utilisant Data Science, NLP et Machine Learning pour aider les candidats à mieux comprendre le marché et leur adéquation avec les offres.

## 🎯 Objectifs du projet

1. **Extraire automatiquement** les compétences des CV et des offres d'emploi
2. **Calculer un score de compatibilité** CV ↔ Offre (matching)
3. **Analyser les compétences manquantes** (Skill Gap)
4. **Recommander des offres** personnalisées
5. **Prédire une fourchette de salaire** selon le profil
6. **Visualiser les tendances** du marché de l'emploi
